A modern, highly interactive, and responsive developer portfolio showcasing software engineering projects, technical skills, and professional experience. Built with performance, accessibility, and sleek UI/UX design in mind.

---

## ✨ Features

- 🎨 **Modern & Sleek UI**: Built with React 18, Tailwind CSS, and smooth Framer Motion animations.
- 📱 **Mobile-First Responsive Design**: Flawless layout adaptivity across all devices and screen sizes.
- 🚀 **Fast Performance**: Powered by Vite for lightning-fast bundling and optimal loading speed.
- 📂 **Featured Projects Showcase**: Detailed cards highlighting full-stack projects, live demos, and GitHub links.
- 🛠️ **Skills & Tech Stack Display**: Categorized visual presentation of core competencies.
- 📬 **Interactive Contact System**: Backend API powered by Express for direct communication.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Tailwind CSS, Framer Motion, Lucide Icons
- **Build Tool**: Vite
- **Backend / Server**: Node.js, Express.js
- **Deployment**: Vercel

## 🚀 Getting Started

Follow these steps to set up and run the portfolio locally on your machine.

### Prerequisites

Ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v18.x or higher)
- [npm](https://www.npmjs.com/) (v9.x or higher)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/prabhatsagardev/prabhat-portfolio.git
   cd prabhat-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:5173`.

4. **(Optional) Start the backend server:**
   ```bash
   npm run server
   ```
